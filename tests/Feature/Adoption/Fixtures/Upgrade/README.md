Encryption uses randomized ciphertext, so regeneration is not byte-identical.
Never use this key or these records outside an isolated test database.

To reproduce, materialize that exact Git revision in a temporary directory,
including its `tests/` files (the release archive excludes them), install its
normal stable dependencies, record the resolved lock, and run from that directory:

```sh

```

`cross-reader.php` exercises the reverse boundary in separate PHP processes:

```sh

php tests/Feature/Adoption/Fixtures/Upgrade/cross-reader.php export /tmp/candidate-rows.json
# From the pinned old checkout:
```
