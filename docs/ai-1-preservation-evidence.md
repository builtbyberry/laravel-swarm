workflow guarantees, native source boundaries, explicit exclusions and later
companion proof. Native generation remains delegated to Laravel AI; no runtime
responsibility is deleted or replaced by this evidence component.

## Supported combinations and operational limits

- `prompt()` / `run()` and declared-class `queue()` / `dispatchDurable()` retain
  sequential, parallel, generated hierarchical and static hierarchical workflows.
  Inline builders remain in-process. Generated queueing defaults to one job;
  opt-in `multi_worker` has branch/join coordination. Static hierarchy does not
  acquire that multi-worker contract.
- Live streaming and broadcast helpers support sequential, generated hierarchy,
  and static hierarchy. The generated coordinator prompts synchronously.
  Top-level parallel live streaming is default-off, process-only, and carries
  explicit branch/attempt/sequence identity without a global order. Structured-
  output streamed workers remain rejected. Native chat protocols do not turn
  Swarm events into Vercel or AG-UI.
- Queued/durable execution needs active-context capture. Production capture
  defaults remain off; designated database columns remain sealed by default.
  Native conversation privacy, authorization and retention are independently
  configured. Swarm capture/sealing does not encrypt native conversation rows.
- Existing signal record-before-release and child claimed-intent recovery limits
  remain characterized by [PreservationBoundsTest](../tests/Feature/Adoption/PreservationBoundsTest.php).
  This adoption does not repair those separately owned recovery concerns. Native
  approval rejection is permanent; ordinary unfinished-node retries can repeat
  provider/tool effects after native completion but before a Swarm checkpoint.
- FrozenView and completed non-final stream checkpoints preserve their bounded
  replay behavior. Checkpoint failures, final/unfinished work and operator retries
  can reexecute effects. Fences protect stored state, not external operations;
  cancellation/timeouts are cooperative, not hard provider cancellation.
- Actual generator/Fiber interleaving and worker reset tests prove the named
  context boundaries, not universal native ambient-state isolation. Durable
  execution retains concrete database-store requirements. Custom native
  ConversationStore compatibility does not expand Swarm durable-store parity.
